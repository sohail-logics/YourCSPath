Phase by Phase

Learning Roadmap

Nine structured phases from complete beginner to production-ready data scientist. Each includes topics, tools, and real courses to guide you forward.

🔢
Phase 1 · Weeks 1–4
Math & Statistics Foundations
Data science is applied mathematics. A solid grasp of probability, statistics, and linear algebra is what separates a person who runs a model from one who truly understands what the model is doing — and why it fails.
Descriptive Statistics Probability Theory Normal Distribution Hypothesis Testing P-values & Confidence Intervals Bayes' Theorem Linear Algebra basics A/B Testing
📚 Courses
  • Statistics & Probability — Khan Academy (Free)
  • Statistics with Python Specialization — U. of Michigan / Coursera
🐍
Phase 2 · Weeks 5–8
Python for Data Science
Python is the undisputed language of data science. Learn the language itself and the core libraries that power every data pipeline — from loading a CSV to building a machine learning model from scratch.
Python Fundamentals NumPy & Arrays Pandas DataFrames Data Cleaning Matplotlib & Seaborn Jupyter Notebooks Scikit-learn basics Working with APIs
📚 Courses
  • Python for Data Science, AI & Development — IBM / Coursera (Free)
  • Python & Pandas — Kaggle Learn (Free)
🗄️
Phase 3 · Weeks 9–11
SQL & Data Querying
Nearly every data science job interview includes SQL. It is the universal language of databases — and most business data lives in relational databases that you query with SQL before any analysis can begin.
SELECT, WHERE, ORDER BY Aggregations & GROUP BY INNER / LEFT / RIGHT JOINs Subqueries & CTEs Window Functions PostgreSQL / MySQL Indexing & Performance SQL + Pandas integration
📚 Courses
  • Intro to SQL & Advanced SQL — Kaggle Learn (Free)
  • SQL for Data Science — UC Davis / Coursera (Free Audit)
📊
Phase 4 · Weeks 12–14
Data Visualization & EDA
Exploratory data analysis is how you understand a dataset before modelling. Visualization turns numbers into stories — and data storytelling is one of the most valued skills in every data science job posting.
Matplotlib & Seaborn Plotly (interactive) Tableau basics Power BI dashboards EDA methodology Distribution analysis Correlation & heatmaps Outlier detection
📚 Courses
  • Data Visualization with Python — IBM / Coursera (Free)
  • Data Visualization — Kaggle Learn (Free)
🧠
Phase 5 · Months 4–5
Machine Learning
This is the core of data science. Learn the classic supervised and unsupervised algorithms that power recommendation systems, fraud detection, churn prediction, and price forecasting across every industry on earth.
Linear & Logistic Regression Decision Trees Random Forest & Gradient Boosting XGBoost / LightGBM K-Means Clustering Dimensionality Reduction (PCA) Model Evaluation (AUC, F1) Feature Engineering
📚 Courses
  • Machine Learning Specialization — Andrew Ng / Stanford / Coursera
  • Intermediate Machine Learning — Kaggle Learn (Free)
🔬
Phase 6 · Month 6
Feature Engineering & Model Tuning
The difference between a good model and a great model is rarely the algorithm — it is the data preparation and tuning. This phase teaches you how to squeeze maximum performance out of your models.
Feature Selection Encoding Categoricals Handling Missing Data Cross-validation Hyperparameter Tuning Grid Search / Optuna Pipelines in Scikit-learn Ensemble Methods
📚 Courses
  • Feature Engineering — Kaggle Learn (Free)
  • Structuring Machine Learning Projects — DeepLearning.AI / Coursera
🔗
Phase 7 · Month 7
Deep Learning & Advanced ML
Deep learning unlocks problems that classical ML cannot solve — image classification, text generation, and time series forecasting at scale. Even data scientists who don't specialize in DL need to understand these techniques.
Neural Network basics TensorFlow / Keras PyTorch introduction CNNs (image tasks) RNNs & LSTMs Transformers & Attention Transfer Learning
📚 Courses
  • Deep Learning Specialization — Andrew Ng / DeepLearning.AI
  • Practical Deep Learning for Coders — fast.ai (Free)
☁️
Phase 8 · Month 8
Big Data & Cloud Platforms
Real-world data doesn't fit in a laptop's memory. Learn how to work with big data tools and cloud platforms that process terabytes of data at scale — the infrastructure that powers production data science at every major company.
Apache Spark (PySpark) Hadoop ecosystem AWS S3 & SageMaker Google BigQuery Azure ML Studio Data Pipelines & ETL Apache Airflow
📚 Courses
  • Introduction to Big Data with Spark and Hadoop — IBM / Coursera (Free)
  • AWS Machine Learning Foundations — AWS / Coursera (Free)
🎯
Phase 9 · Month 9+
Choose Your Specialization
You now have a complete data science foundation. Pick the domain that excites you most — each is a distinct career with its own tools, market demand, and salary ceiling.

Specializations

Data science is an umbrella field — after the foundation, it branches into five distinct disciplines each with its own career trajectory and salary ceiling.

Data Analysis
📊 Data Analysis & BI
Analyst · The Most Accessible Entry Point
Data analysts are the most in-demand entry-level data professionals — accounting for 18% of all data job postings. They clean, query, and visualize data to answer business questions. Every company regardless of size needs analysts, making this the fastest track from study to your first job. Strong SQL, Excel, and Tableau skills plus a portfolio can get you hired within 6 months.
SQL (Advanced) Excel / Google Sheets Tableau / Power BI Python (Pandas) Data Storytelling A/B Testing
Data Engineering
🔧 Data Engineering
Engineer · Build the Pipelines
Data engineers build the infrastructure that data scientists rely on — pipelines, databases, and data warehouses that move and store data reliably. Data engineers are among the highest-paid professionals in the data space, often earning more than data scientists at the same level of experience. With 20% of all data job postings targeting engineers, the demand is enormous and the skills gap is significant.
Apache Spark Kafka dbt (data build tool) Airflow Snowflake / Redshift AWS / GCP
ML / AI Science
🧠 ML / AI Data Scientist
Scientist · Predictive Modelling at Scale
The core data scientist role that most people envision — building predictive models, running experiments, and turning complex datasets into business decisions. ML skills add a 25% salary premium over baseline data science. Specialists with deep learning or NLP expertise earn 30% above market rate. This is the highest-ceiling specialization within data science for those who want to work at the intersection of research and engineering.
Scikit-learn TensorFlow / PyTorch XGBoost Experiment Design Model Deployment MLflow
Business Intelligence
📈 Business Intelligence
BI · Data-Driven Decision Making
BI analysts sit at the intersection of data and business strategy, turning dashboards and reports into decisions. Every Fortune 500 company maintains a dedicated BI team. BI specialists who understand both the technical and business sides command salaries rivalling software engineers. With tools like Tableau, Power BI, and Looker, BI professionals are in demand across finance, retail, healthcare, and logistics equally.
Tableau Power BI Looker / Metabase SQL (Advanced) KPI Design Business Acumen
Research Science
🔍 Research Science
Research · Pushing the Frontier
Research scientists work at the bleeding edge of what's possible — publishing papers, inventing new algorithms, and solving problems that have no established solution yet. Companies like DeepMind, Meta AI, OpenAI, and Google Brain employ research scientists at $200K–$500K+. While typically requiring a PhD for the most elite roles, many industry research positions are accessible to strong self-taught engineers with a portfolio of publications or notable projects.
Research Methodology Academic Writing PyTorch (deep) arXiv / Papers with Code Experiment Design Statistical Rigor

From Student to Expert

Career Growth Timeline

A realistic picture of your data science journey. The field is unique in that you can enter as a data analyst and progress to data scientist — each stage building directly on the last.

Learning Phase
Months 1–6 — Foundations, Python, SQL & Visualization
Building Your Data Foundation
Study statistics, Python, SQL, and data visualization. Build 3–5 real projects using public datasets from Kaggle and government sources. Start competing in Kaggle competitions — even participation shows initiative. Earn Google Data Analytics or IBM Data Science certificate. Begin applying for data analyst roles at month 5 — you already have enough skills to be productive in many entry-level positions.
✓Python & SQL solid ✓3 Kaggle projects done ✓Google or IBM cert earned ✓LinkedIn portfolio active
First Job
Months 6–12 — Data Analyst / Junior Data Scientist
Your First Data Role
💰 $65K–$95K (Analyst) · $80K–$105K (Junior Data Scientist)
Data analyst is the most accessible first data role and the natural entry point to data science. You are cleaning data, writing SQL queries, building dashboards, and answering business questions. While working, continue learning ML — the Andrew Ng Machine Learning Specialization is the standard progression. Many analysts make the full transition to data scientist within 12–18 months in this role.
✓First data role secured ✓SQL used daily in production ✓ML Specialization in progress ✓First dashboard shipped
Early Career
Year 1–2 — Data Scientist
Data Scientist
💰 $100K–$130K
You are now building and deploying predictive models that directly influence business decisions. You run A/B experiments, build recommendation systems, detect anomalies, and forecast demand. ML skills add a 25% salary premium at this level. Cloud certification (AWS ML or Azure DP-100) significantly expands your opportunities at larger companies. Start picking your specialization — BI, data engineering, or ML science.
✓First model in production ✓Specialization deepening ✓Cloud cert in progress ✓A/B experiments running
Career Growth
Year 2–4 — Senior Data Scientist / Lead Analyst
Senior Data Scientist / Data Engineering Lead / BI Manager
💰 $130K–$165K
Senior data scientists own complete analytical systems — from data collection through modelling, deployment, and monitoring. You are defining the team's technical direction, mentoring junior staff, and presenting findings to executives. Deep learning or NLP expertise at this stage adds a 30% salary premium. Many seniors begin transitioning into staff or principal roles or moving into people management.
✓Senior role secured ✓Leading analytical strategy ✓Advanced cloud cert earned ✓Presenting to executives
Expert Level
Year 4–6 — Principal / Staff / Director
Principal Data Scientist / Director of Data Science / Head of Analytics
💰 $160K–$220K
Principal and staff-level data scientists define data strategy across entire organizations. Directors of Data Science oversee teams of 10–30 analysts and scientists, establish data governance, and align technical capabilities with business goals. Top-paying industries for this level include finance, pharmaceuticals, and tech. FAANG data science directors and principal scientists earn $250K–$400K in total compensation.
✓Principal or Director role ✓Team of 10+ managed ✓Data strategy ownership ✓Conference speaking
Leadership
Year 6+ — CDO / VP / Chief Data Officer
Chief Data Officer / VP of Data Science / Research Scientist
💰 $200K–$450K+
The ceiling in data science is extraordinary. Chief Data Officers at Fortune 500 companies earn $250K–$600K. Research scientists at AI labs like DeepMind and Google Brain earn $300K–$700K in total compensation. The top 10% of data scientists in the US earn over $194,410 in base salary alone — and that number climbs significantly when equity and bonuses are included. The BLS projects 23,400 new data scientist openings every year for the next decade.
✓CDO or VP Data role ✓Industry thought leader ✓$200K+ base achievable ✓Consulting opportunities

Data science stands out as one of the most accessible paths to a six-figure salary in technology. The median salary is $112,590 according to the US Bureau of Labor Statistics — and the top 10% earn over $194,410. What makes this field uniquely compelling is the clear progression: you can enter as a data analyst with just Python and SQL skills, earn $65K–$80K, and grow into a full data scientist role within 12–18 months. Every company in every industry now needs data professionals — from healthcare and finance to logistics, retail, and government. Unlike many technical careers, data science rewards curiosity, storytelling ability, and domain expertise just as much as pure coding skills. With 34% projected job growth through 2034 and 23,400 new openings every single year, data science is among the safest long-term career bets in all of technology.
